```mermaid
sequenceDiagram
    participant 用户 as 用户
    participant 前端 as 前端
    participant 后端 as 后端
    participant 数据库 as 数据库
    participant JWT工具 as JWT工具

    用户->>前端: 输入账号密码
    activate 前端
    前端->>后端: POST /user/login
    deactivate 前端
    activate 后端
    后端->>数据库: 查询用户信息
    activate 数据库
    数据库-->>后端: 返回用户数据
    deactivate 数据库

    alt 用户不存在
        后端-->>前端: 返回错误
        activate 前端
        前端-->>用户: 提示用户不存在
        deactivate 前端
        deactivate 后端
    else 密码错误
        后端-->>前端: 返回错误
        activate 前端
        前端-->>用户: 提示密码错误
        deactivate 前端
        deactivate 后端
    else 用户被禁用
        后端-->>前端: 返回错误
        activate 前端
        前端-->>用户: 提示账号已禁用
        deactivate 前端
        deactivate 后端
    else 登录成功
        后端->>JWT工具: 生成Token
        activate JWT工具
        JWT工具-->>后端: 返回Token
        deactivate JWT工具
        后端-->>前端: 返回用户信息+Token
        deactivate 后端
        activate 前端
        前端-->>用户: 登录成功
        deactivate 前端
    end
```
